# Music for the portfolio

Add an MP3 here and its metadata to `src/data/music.json`. Aim for 128–192 kbps and under 5 MB per track.

Each entry needs `src` (such as `music/recording.mp3`), `title`, `artist`, `license`, and `source`. Use one of `own`, `CC0`, `CC-BY-4.0`, or `Pixabay Content License`. Use the source URL or `own recording` for your own recording. Enter the original artist and source URL for CC BY 4.0 so the player can show the attribution. Use `Permission granted` with an HTTP(S) source URL for a recording you have permission to publish on this site. Only publish tracks you are allowed to redistribute.

The header control appears when tracks are available. Visitors start playback themselves.
