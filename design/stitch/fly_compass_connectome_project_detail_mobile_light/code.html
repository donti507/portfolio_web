Section 01

The Question

How does a miniature biological circuit consisting of fewer than 500 neurons sustain sub-degree angular orientation over prolonged dark navigation, when physical electron-microscopy traces exhibit continuous synaptic rewiring and stochastic turnover?

psychology_alt

Classical ring-attractor models rely on immaculate, symmetric connectivity matrices. Real animal brains, however, are asymmetric, noisy, and subject to dendritic remodelling. We asked: what mathematical invariants insulate the fly’s internal compass from biological disorder?

Section 02

Why It Matters

Current artificial neural architectures (like state-space models and recurrent spatial memory blocks) deteriorate rapidly when neuromorphic weights undergo thermal noise or quantization compression. Decoding the fly’s topological fault tolerance yields robust spatial primitives for energy-constrained edge robotics.

1

Neuromorphic Hardware

Demonstrating that continuous attractors survive uncalibrated memristor non-linearities without active external tuning.

2

Theoretical Neurobiology

Providing an analytical bound on maximum eigenvalue perturbation before attractor manifold collapse occurs.

Section 03

What I Did

A four-stage pipeline integrating volume EM connectomics with non-linear dynamical systems theory:

Method 01 Janelia NeuPrint

Connectomic Extraction & Graph Truncation

Queried and sanitized 433 EPG (Ellipsoid body–Protocerebral bridge–Gall) and PEN (Protocerebral bridge–Ellipsoid body–Noduli) neurons, indexing 12,840 validated synaptic junctions.

Method 02 Monte Carlo

Stochastic Synaptic Drift Injection

Simulated post-mitotic synaptic decay via Poisson turnover models with varying degrees of correlated spine elimination (5% to 45% matrix corruption).

Method 03 RK4 / Brian2

Continuous Spike-Time Dynamic Simulation

Executed 1,200 hours of virtual flight trajectories using conductance-based leaky integrate-and-fire equations with realistic synaptic conductance kinetics.

Method 04 Topology Analysis

Manifold Manifold Persistent Homology

Extracted Betti numbers β₀ and β₁ over population activity vectors to confirm whether the functional representational space retained topological circularity.

Section 04

What I Found

The empirical connectome contains structural compensation mechanisms absent from textbook symmetric ring attractor formulations:

check_circle Degenerate Attractor Invariance

Phase bump stability remains invariant to random synaptic dropouts up to 22%, attributable to widespread recurrent inhibitory loops in the wedge-gall interneurons.

check_circle Topological Ring Preservation

Persistent homology confirms that the first Betti number β₁ = 1 is preserved across all simulated adult developmental transitions.

bolt Asymmetry Dampens Catastrophic Drift

Anatomical left-right asymmetries—long suspected to be developmental flaws—actively function as anchor pins preventing rotational runaway during velocity quiet periods.

check_circle Sub-Degree Velocity Integration

Angular tracking error accumulated at merely 0.3° to 1.6° per second, matching living tethered fly optical recordings under wild conditions.

Section 05

What This Does Not Show

balance Boundary Conditions & Caveats
  • • Single Individual Connectome: The source electron microscopy volume originates from a single female brain; inter-individual variance cannot yet be cross-validated.
  • • Non-Peptidergic Transmission: Modulatory monoamines (octopamine, dopamine) that tune behavioral states were not modeled dynamically.
  • • No Optical Feedback: The current proof assumes dead-reckoning (idiothetic path integration) in total absence of celestial visual cues.
Section 06

Reproduce It

Clone the verified computational notebook and reproduce Figure 01 in ~6 minutes on a standard Apple Silicon or Linux workstation:

Terminal · bash 
# 1. Clone repository & install dependencies
git clone https://github.com/mdaliashrafyad/fly-compass-connectome.git
cd fly-compass-connectome
pip install -r requirements.txt

# 2. Download cached NeuPrint adjacency matrices
python scripts/fetch_hemibrain.py --version v1.2.1

# 3. Run non-linear drift benchmark & regenerate Figure 1
python run_attractor_eval.py --drift-ratio 0.15 --output fig1.png
